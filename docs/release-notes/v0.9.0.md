# v0.9.0 — first release

tar-dedup is a `tar` "wrapper" that **deduplicates a file tree before
archiving**, for efficient cold storage of unstructured data.

## In this release

- **tar-dedup** — CLI: resumable `archive`/`extract` pipelines, sparse-file
  materialization, and rich per-file metadata capture (times, uid/gid, mode,
  xattrs, ACLs, SELinux, symlink targets).
- **tar-dedup-lib** — the library backing the CLI, driven by a work-directory
  SQLite state machine (resumable across runs).
- **sparse-cp** — sparse-aware copy + zero-block scanner used during
  sparsification.

## Install

```
cargo install tar-dedup
```

(Also available on crates.io: `tar-dedup-lib`, `sparse-cp`.)

## Highlights

- Deduplicates by content (SHA-1 canonical-payload names).
- Resumable: interrupted archive/extract runs pick up where they left off.
- xz-as-default compression; gzip/bzip2/zstd also supported.
- Standard `.tar` container with a seekable SQLite footer (manifest +
  snapshot checkpoints).
- License: GPL-3.0-or-later.

## Platform notes

- Linux binaries shipped for `x86_64` and `aarch64`.
- macOS/Windows builds are not yet available — the Linux-specific
  dependency set (`selinux`, `acl`) still needs target gating.
