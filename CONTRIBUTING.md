# Contributing to tar-dedup

Thanks for considering a contribution! This project is
[GPL-3.0-or-later](LICENSE.txt). By submitting any contribution — a pull
request, commit, patch, or issue attachment — you agree to the
[Contributor License Agreement](CLA.md) (a broad grant that lets the project
be relicensed or folded into a foundation later without re-collecting your
consent). You keep ownership of your own work.

## Steps

1. Fork the repository and create a branch.
2. Make your change; keep commits focused and messages descriptive.
3. Open a pull request against `main`.
4. On your first contribution, the **CLA bot** will ask you to sign the
   agreement (see below). It must pass before merge.

## Signing the CLA

The project uses **CLA Assistant**. When your first pull request is opened, the
bot posts a link that takes you through a browser-based sign-in. Signing is
one-time and recorded against your GitHub identity. The bot reports its status
as a required check — the PR cannot merge until it passes.

## Commit sign-off

Each commit should carry a `Signed-off-by:` trailer confirming you wrote and
are entitled to contribute it:

```
git commit -s -m "Your message"
```

## Code of conduct

Be respectful and constructive. Personal attacks, harassment, or trolling are
not tolerated.
